Three-Tier AI Pipeline Architecture

A sequential framework designed for transparent, explainable decision-making without black-box API dependencies.

Layer 1
Signal Extraction & Safety

Trained Logistic Regression classifiers analyze TF-IDF features for Toxicity, Sarcasm, and Sentiment. Serves as an automated safety gatekeeper that flags toxic submissions.

Toxicity · Sarcasm · Sentiment Signals
Layer 2
Probabilistic Support Modeling

A Bayesian Network (built with pgmpy) models uncertainty by fusing text signal probabilities with factual evidence and relevance indicators to calculate posterior support probabilities: P(Support_A) and P(Support_B).

P(Support_A) vs P(Support_B) Posterior
Layer 3
Constraint Satisfaction (CSP)

A custom CSP Solver enforces strict domain rules. It guarantees fair consideration, enforces confidence thresholds, and returns an Inconclusive verdict whenever evidence is insufficient or tied.

Zero Rule Violations · Inconclusive Fallback
